- 🛠 **独立开发者** —— 习惯一个人把一个想法从原型推到能上线的产品
- 📱 主力技术栈 **Flutter / Dart**，以 Android 端为主，必要时下沉到原生；服务端写 **Go / Python**
- 🔒 相信工具该在**本地**解决问题：小鲸鱼的解析全程跑在手机上，链接不经过任何第三方服务器
- 🧪 喜欢把踩过的坑沉淀成能复用的方案，而不是一次性脚本
- 🚀 信奉「**先做出来，再做好**」
- 📫 交流走 Issue 就行，每个仓库都开着
