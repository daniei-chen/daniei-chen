## 🧑‍💻 关于我

- 🛠 **独立开发者** —— 习惯一个人把一个想法从原型推到能上线的产品
- 📱 主力技术栈 **Flutter / Dart**，以 Android 端为主，必要时下沉到原生
- 🔒 相信工具该在**本地**解决问题：小鲸鱼的解析全程跑在手机上，链接不经过任何第三方服务器
- 🧪 喜欢把踩过的坑沉淀成能复用的方案，而不是一次性脚本
- 🚀 信奉「**先做出来，再做好**」
- 📫 交流走 Issue 就行，每个仓库都开着

### 🐳 小鲸鱼

[![Repo](https://img.shields.io/badge/daniei--chen/Little--Whale-22D3EE?style=flat-square&logo=github&logoColor=white)](https://github.com/daniei-chen/Little-Whale)
[![Stars](https://img.shields.io/github/stars/daniei-chen/Little-Whale?style=flat-square&color=F472B6&label=stars)](https://github.com/daniei-chen/Little-Whale/stargazers)

粘贴链接，保存**无水印原片**。支持抖音 · 小红书 · 哔哩哔哩 · 微博 · 快手 · 知乎。

解析**全程在手机本地完成**——链接不上传、不经过任何服务器，走平台原始资源而不是压缩过的展示图。Releases 页直接下 APK。

### 📱 ZCode-App

[![Repo](https://img.shields.io/badge/daniei--chen/ZCode--App-A78BFA?style=flat-square&logo=github&logoColor=white)](https://github.com/daniei-chen/ZCode-App)
[![Stars](https://img.shields.io/github/stars/daniei-chen/ZCode-App?style=flat-square&color=F472B6&label=stars)](https://github.com/daniei-chen/ZCode-App/stargazers)

在手机或平板上**远程管理 ZCode 桌面任务**。扫码或粘贴控制链接即可接入，命名并保存设备后一键回到最近的会话。

原生 Flutter 外壳承载设备管理与通知，会话页用 WebView 还原桌面端的布局与交互。MIT 协议。
