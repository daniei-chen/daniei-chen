# 海风里的作品

主页使用蓝白海岸、帆船与小鸟骑行，把作品展示和一点日常的创造感放在一起。正文使用 GitHub 原生 Markdown，项目标题、说明和链接都是真实文本。

## 维护

- 修改主页文字或精选作品：编辑 `tools/make_readme.py`，再运行 `python tools/make_readme.py`。
- 检查插画与生成结果：运行 `python tools/make_readme.py --check`。
- 每日工作流只拉取公开仓库信息、更新额外仓库索引。不会重新生成或覆盖 `assets/coastal/` 的插画。
- 新仓库自动出现在“更多仓库与小实验”；空仓库标注“筹备中”，不冒充已完成产品。

## 视觉资源

`assets/coastal/` 的五幅插画为本次改版专门生成的原创 AI 视觉，使用内置 Image Gen：桌面与窄屏海岸骑行、面向海面的窗、蓝白海浪、手记与铅笔。它们是封面插画，不是产品截图，不含真实账户、密钥、调用或业务数据。`picture` 根据屏宽选择可读的横幅，重要项目文字保持为真实文本。

作品的具体功能、安装、界面截图和支持范围以各项目仓库为准。
