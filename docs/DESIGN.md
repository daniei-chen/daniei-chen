# 海风里的作品

主页保留蓝色海面和骑车小鸟，加入智汇网站现有的夕照、木栈道、青绿单车与花篮，让冷暖自然交替。正文使用 GitHub 原生 Markdown；标题、介绍和入口均为真实文本。

## 排版

智汇、智境始终排在最前。原本两列主项目表格改为开放的图文介绍，不再使用外框或竖线。主项目插画占正文宽度 46%，右对齐，文字自然环绕；`br clear="all"` 防止浮动进入下一个项目。两项之间保留一段自然空白。

ZCode App、小鲸鱼、DSH Token Insight 继续逐项介绍，配图占 32%。标题、说明、下载和项目入口均可选择、可访问。页尾以“一点关于我”和简短致意收束。GitHub 的背景、文字颜色、字体与主题由平台控制，主页用真实图片和内容节奏表达颜色与留白，不依赖会被过滤的样式。

## 视觉资源

`assets/coastal/` 保留既有七幅原创 AI 插画，本轮没有重新生成或涂改这些素材。当前主画面使用海岸横幅（桌面与窄屏）、智境露台、海窗、海浪与手记。

`zhihui-velo-sunset.webp` 原样复用智汇网站已经发布的场景海报，1000 × 720，暖色木栈道、青绿色单车与花篮。该场景由智汇项目改编自 [Jacory Ou / Pelican · Velo](https://github.com/JacoryOu/pelican-velo)，遵循 MIT，完整许可保存在 `assets/coastal/PELICAN-VELO-LICENSE.txt`，页尾同时保留来源链接。它是网站场景海报，不是网关控制台截图。

本轮内置图片服务返回上游连接失败，没有产生新图片，也未使用任何备用 API、外部凭据或手工滤镜来代替。页面通过已有场景完成了暖色引入。

## 维护

- 修改主页：编辑 `tools/make_readme.py`，运行 `python tools/make_readme.py`。
- 检查图片、许可和生成结果：运行 `python tools/make_readme.py --check`。
- 每日工作流只更新公开数据与额外仓库索引，不重新生成或覆盖插画。
- 新仓库进入“更多仓库与小实验”；空仓库标注“筹备中”。

各项目具体功能、安装与支持范围以对应仓库为准。仅个人主页仓库接受本轮修改。
